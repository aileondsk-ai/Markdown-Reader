## 2. 페이지별 확인 항목

### 2.1 SIT 테스트 (`/test`)
- [ ] 질문/옵션 버튼이 한 화면에 잘리지 않고 스크롤 가능
- [ ] 옵션 버튼 터치 영역 충분(최소 48px 높이)
- [ ] 진행률 바·질문 번호 가독성
- [ ] 결과 화면: 유형 코드·닉네임·키워드·ShareCard 카드가 뷰포트에 맞게 표시
- [ ] 결과 화면: "저장" / "공유하기" / "텍스트 복사" 버튼이 겹치지 않고 누르기 쉬움
- [ ] "프로필 보기", "AI 평가 시작하기" 버튼 접근 가능

### 2.2 패션 평가 (`/evaluate`)
- [ ] 페르소나 탭·이미지 업로드 영역이 좁은 화면에서도 사용 가능
- [ ] 결과: 레이더 차트·피드백·ShareCard 영역 레이아웃 깨짐 없음
- [ ] 다중 이미지 업로드 시 개별 카드 스크롤·가독성

### 2.3 코디 추천 (`/recommend`)
- [ ] 계절/상황 선택 UI가 모바일에서 스크롤·탭 동작 정상
- [ ] 추천 카드·다이얼로그가 작은 화면에서 닫기·스크롤 가능

### 2.4 공통 (Navbar, Footer, ShareCard)
- [ ] 네비게이션 메뉴가 좁은 화면에서 접기/펼치기 동작
- [ ] ShareCard 이미지 비율·버튼 영역이 320px에서도 사용 가능
- [ ] 푸터 링크·텍스트 줄바꿈
