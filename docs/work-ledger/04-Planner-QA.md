## 테스트 시나리오 초안

**실행 방법**: 로컬 `npm run dev` 후 브라우저에서 수동 확인. (E2E 자동화는 추후 도입 시 보강.)

### SIT 테스트 (Frontend: Test.tsx)
- [ ] 비로그인 시 테스트 진행 → 결과 제출 시 로그인 유도 또는 401 처리 확인
- [ ] 12문항 전체 응답 후 결과 화면 표시 (유형 코드, 닉네임, 키워드, ShareCard)
- [ ] 결과 화면에서 "저장" / "공유하기" / "텍스트 복사" 동작
- [ ] "프로필 보기", "AI 평가 시작하기" 이동
- [ ] **접근성**: 결과 표시 시 포커스가 결과 영역으로 이동하는지, 스크린 리더로 진행률 안내 확인

### 패션 평가 (Frontend: Evaluate.tsx)
- [ ] 이미지 업로드 → 페르소나 선택 → 평가 결과(레이더 차트, 피드백) 표시
- [ ] 평가 결과 화면에서 ShareCard(OUTFIT) 저장/공유/텍스트 복사
- [ ] 다중 이미지(2장 이상) 업로드 → 배치 분석 → 종합 피드백 + 개별 카드

### 코디 추천 (Frontend: Recommend.tsx, Backend: /api/recommendations)
- [ ] 계절/상황 선택 → 추천 생성 → 아웃핏 세트·이유·대안 표시
- [ ] 로그인 사용자 SIT가 있으면 추천 프롬프트에 유형 반영되는지 확인 (API/로그)
- [ ] 즐겨찾기 토글 및 목록 반영

### 인증 (Backend: auth)
- [ ] 로컬: /api/login 호출 시 mock 유저로 로그인
- [ ] Replit: OpenID 로그인 플로우

## 알파 검증 체크리스트 (시나리오 ↔ 확인 방법/경로)

로컬 `npm run dev` 실행 후 아래 경로·동작으로 시나리오별 통과 여부를 체크할 수 있습니다.

| # | 시나리오 | 확인 방법/경로 |
|---|----------|----------------|
| 1 | SIT 비로그인 시 결과 제출 → 로그인 유도 또는 401 | `/test` 접속 후 로그아웃 상태에서 12문항 응답 → 결과 제출 시 로그인 유도 또는 API 401 확인 |
| 2 | SIT 12문항 후 결과 화면 (유형·닉네임·키워드·ShareCard) | `/test` → 12문항 모두 선택 후 제출 → 결과 영역에 유형 코드·닉네임·키워드·ShareCard 노출 확인 |
| 3 | SIT 결과 화면 "저장/공유하기/텍스트 복사" | 결과 화면에서 각 버튼 클릭 → 저장·공유·복사 동작 및 피드백 확인 |
| 4 | SIT "프로필 보기", "AI 평가 시작하기" 이동 | 결과 화면 CTA 클릭 → `/profile`, `/evaluate` 이동 확인 |
| 5 | SIT 접근성(포커스·스크린 리더) | 결과 표시 후 포커스가 결과 영역으로 이동하는지, 진행 시 진행률/질문 번호 스크린 리더 안내 확인 |
| 6 | 패션 평가 업로드→페르소나→결과(레이더·피드백) | `/evaluate` → 이미지 업로드 → 페르소나 선택 → 레이더 차트·피드백·ShareCard(OUTFIT) 확인 |
| 7 | 패션 평가 ShareCard 저장/공유/텍스트 복사 | 평가 결과 하단 "결과 공유하기"에서 저장·공유·텍스트 복사 동작 확인 |
| 8 | 패션 평가 다중 이미지(2장 이상) | `/evaluate`에서 2장 이상 업로드 → 배치 분석 → 종합 피드백 + 개별 카드 표시 확인 |
| 9 | 코디 추천 계절/상황→추천→아웃핏·이유·대안 | `/recommend` → 계절·상황 선택 → 추천 생성 → 아웃핏 세트·이유·대안 표시 확인 |
| 10 | 추천 시 SIT 유형 반영 | 로그인 + SIT 제출 완료 후 `/recommend`에서 추천 생성 → 서버 로그 또는 응답에 sitType 반영 확인 |
| 11 | 추천 즐겨찾기 토글 및 목록 반영 | 추천 상세에서 즐겨찾기 토글 → 추천 목록/프로필에서 반영 확인 |
| 12 | 로컬 로그인(mock) | REPL_ID 없이 `/api/login` 호출 또는 로그인 버튼 → mock 유저로 로그인 확인 |
| 13 | Replit OpenID 로그인 | Replit 배포 환경에서 로그인 플로우 진행 후 세션 확인 |
| 14 | 로그아웃 후 401 | 로그아웃 후 인증 필요 API(예: `/api/sit/latest`) 호출 → 401 응답 확인 |
