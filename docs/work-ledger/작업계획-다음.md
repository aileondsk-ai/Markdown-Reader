# 다음 작업 계획

> 업무노트 01~04 "다음 작업" 확인 후, 실행 가능한 항목 중심으로 계획·수행

---

## 1. 현황 요약

| 파트 | 다음 작업 (미완료) | 실행 가능 여부 |
|------|-------------------|----------------|
| 01 Frontend | SIT 결과 페이지 실제 기기/다양한 뷰포트 수동 QA (권장) | 수동 작업 → **뷰포트별 확인 포인트** 문서화로 대체 |
| 02 Backend | (선택) 프로덕션 스키마 변경 시 db:generate → migrate | 선택·조건부 → **다음 제안** 1개 추가 |
| 03 AI | SIT 알고리즘 문항 가중치 등 추가 검증 필요 시만 | 필요 시만 → 유지, **다음 제안** 1개 추가 |
| 04 Planner | 알파 로컬에서 테스트 시나리오 일부 실행·체크 | 실행 가이드 있음 → **알파 검증 체크리스트**로 시나리오↔확인방법 1:1 매핑 |

---

## 2. 수행 계획

| # | 작업 | 산출물 |
|---|------|--------|
| 1 | **04 Planner**: 알파 검증 체크리스트 | 테스트 시나리오 각 항목에 "확인 방법/경로" 한 줄 추가, 로컬 실행 시 체크하기 쉽게 정리 |
| 2 | **01 Frontend**: 뷰포트별 확인 포인트 | 01 또는 04에 SIT 결과 페이지 "뷰포트별 확인 포인트"(320/768/1024px 등) 짧은 목록 추가 |
| 3 | **01·02·03**: 다음 작업 보강 | 남은 "다음 작업"이 적은 파트에 실행 가능한 제안 1개씩 추가 (추후 수행용) |
| 4 | **업무노트 갱신** | 이번 세션 완료 반영 |

---

## 3. 실행 순서

1. 04 알파 검증 체크리스트
2. 01 뷰포트별 확인 포인트
3. 01·02·03 다음 작업 제안 추가
4. 업무노트 이번 세션 완료 기록

---

## 4. 실행 완료

- **04**: 알파 검증 체크리스트 표 추가 (시나리오 9항목 ↔ 확인 방법)
- **01**: 뷰포트별 확인 포인트 표 추가, 다음 작업에 History/Progress/Profile 접근성 제안 추가
- **02**: 다음 작업에 API 401 응답 형식 통일 점검 제안 추가
- **03**: 다음 작업에 챗봇 프롬프트 분리 검토 제안 추가
- **01~04** 업무노트 "이번 세션 완료" 갱신
