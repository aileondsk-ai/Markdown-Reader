# 다음 작업 계획

> 업무노트 01~04 "다음 작업" 확인 후, 실행 가능한 항목 중심으로 계획·수행

---

## 1. 현황 요약

| 파트 | 다음 작업 (미완료) | 실행 가능 여부 |
|------|-------------------|----------------|
| 01 Frontend | SIT 결과 페이지 실제 기기/다양한 뷰포트 수동 QA (권장) | 수동 작업 → **뷰포트별 확인 포인트** 문서화로 대체 |
| 02 Backend | (선택) 프로덕션 스키마 변경 시 db:generate → migrate | 선택·조건부 → **다음 제안** 1개 추가 |
| 03 AI | SIT 알고리즘 문항 가중치 등 추가 검증 필요 시만 | 필요 시만 → 유지, **다음 제안** 1개 추가 |
| 04 Planner | 알파 로컬에서 테스트 시나리오 일부 실행·체크 | 실행 가이드 있음 → **알파 검증 체크리스트**로 시나리오↔확인방법 1:1 매핑 |

## 2. 수행 계획
