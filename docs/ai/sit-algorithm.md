# SIT 알고리즘 명세

> Style Identity Type · 16가지 유형 산출 로직

---

## 1. 개요

- **입력**: 12문항 답변 `Record<q1~q12, "I"|"E"|"W"|"C"|"S"|"N"|"M"|"B">`
- **출력**: 4축 점수 `{ IE, WC, SN, MB }` (0~100), 4글자 코드 (예: `IWSM`)

---

## 2. 축별 문항 수 및 변동치

| 축 | 의미 | 문항 수 | 선택값 | 축당 변동 |
|----|------|---------|--------|-----------|
| IE | 표현 방향 | 3 | I / E | 1문항당 ±17 |
| WC | 스타일 온도 | 3 | W / C | 1문항당 ±17 |
| SN | 변화 성향 | 3 | S / N | 1문항당 ±17 |
| MB | 디테일 관심도 | 3 | M / B | 1문항당 ±17 |

- **기본값**: 각 축 50 (중간).
- **1문항 선택**: 해당 축에 +17(두 번째 문자 선택 시) 또는 -17(첫 번째 문자 선택 시).
- **3문항 후**: 50 + 17×k - 17×(3-k) = 50 + 34k - 51 = -1 + 34k.  
  k=0 → 50-51=-1 → 클램핑 후 0, k=3 → 50+51=101 → 클램핑 후 100.  
  즉 각 축은 **0, 17, 34, 51, 67, 84, 100** 등 17 단위로 변동 가능.

---

## 3. 경계값 50

- **50 미만**: 첫 번째 문자 (I, W, S, M)
- **50 이상**: 두 번째 문자 (E, C, N, B)
- **정확히 50**: 3문항 모두 첫 번째 선택 시 50-51=-1 → 0으로 클램핑되므로 0.  
  모두 두 번째 선택 시 101 → 100.  
  따라서 **실제로 50이 나오는 경우는 없음** (0 또는 17 이상).  
  구현상 `>= 50`이면 두 번째 문자이므로, 50이면 E/C/N/B로 분류됨 (현재 코드와 일치).

---

## 4. 검증 요약

| 검증 항목 | 결과 |
|-----------|------|
| 경계값 50 | 50 이상 → E/C/N/B, 미만 → I/W/S/M. 일관됨. |
| 변동치 17 | 3문항 × 17 = 51, 50±51로 0~100 범위 유지. |
| 클램핑 | 0~100으로 제한. |
| 코드 산출 순서 | IE → WC → SN → MB (4글자 조합). |
