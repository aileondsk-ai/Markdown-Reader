## Executive Summary

StyleFinder AI는 "나를 찾아가는 플랫폼" 생태계에서 **외적인 나를 표현하는** 서비스입니다. 기존 스타일 상담 중심 기획에서 **패션 평가**와 **패션 추천** 두 축으로 재편하며, MBTI처럼 사용자의 스타일 정체성을 분류하는 **Style Identity Type(SIT)** 체계를 도입합니다.

### 핵심 가치 제안
- **문제**: 사용자는 자신에게 어울리는 스타일을 모르며, 타인의 시선을 객관적으로 알기 어려움
- **해결**: 다양한 페르소나 기반 패션 평가 + 멀티모달 데이터 분석 기반 맞춤 추천
- **차별점**: 단순 추천이 아닌 "나의 스타일 정체성"을 발견하는 여정 제공

# 1. 서비스 아키텍처 개요

## 1.1 핵심 기능 구조

```
StyleFinder AI
├── 🔍 패션 평가 (Fashion Evaluation)
│   └── 다양한 페르소나 관점에서 내 사진 평가
│
├── 👔 패션 추천 (Fashion Recommendation)  
│   ├── 사전 데이터 수집 (프로필 구축)
│   │   ├── 카카오톡 메시지 분석
│   │   ├── 목소리 녹음 분석
│   │   ├── 사진 분석
│   │   └── 신체 정보 (키, 몸무게)
│   │
│   └── 주제별 맞춤 추천
│       ├── 상황별 (데이트, 면접, 일상 등)
│       ├── 계절별
│       └── 스타일 컨셉별
│
└── 🎯 스타일 정체성 (Style Identity Type)
    └── MBTI형 스타일 분류 체계
```

# 2. Style Identity Type (SIT) - 스타일 정체성 분류 체계

## 2.1 분류 체계 설계 철학

MBTI가 심리적 선호를 4개 축으로 분류하듯, SIT는 스타일 선호와 표현 방식을 4개 축으로 분류합니다.

### 설계 원칙
1. **직관성**: 누구나 자신의 유형을 쉽게 이해할 수 있어야 함
2. **변별력**: 각 유형이 명확히 구분되어야 함
3. **활용성**: 실제 패션 추천에 적용 가능해야 함
4. **재미요소**: SNS 공유 욕구를 자극해야 함

## 2.2 4개 축 정의

### 축 1: 표현 방향 (Expression Direction) - I/E
| 코드 | 명칭 | 설명 | 특징 |
|------|------|------|------|
| **I** | Inward (내향 표현) | 자신을 위한 스타일 | 편안함 우선, 자기만족 중심, 과시 지양 |
| **E** | Expressive (외향 표현) | 타인에게 보여주는 스타일 | 시선 의식, 트렌드 민감, 인상 관리 중시 |

### 축 2: 스타일 온도 (Style Temperature) - W/C
| 코드 | 명칭 | 설명 | 특징 |
|------|------|------|------|
| **W** | Warm (따뜻한) | 부드럽고 친근한 인상 | 라운드 실루엣, 따뜻한 색감, 부드러운 소재 |
| **C** | Cool (차가운) | 날카롭고 세련된 인상 | 직선 실루엣, 차가운 색감, 구조적 소재 |

### 축 3: 변화 성향 (Change Tendency) - S/N
| 코드 | 명칭 | 설명 | 특징 |
|------|------|------|------|
| **S** | Stable (안정형) | 검증된 스타일 고수 | 시그니처 아이템 선호, 느린 변화, 클래식 지향 |
| **N** | Novel (변화형) | 새로운 시도 즐김 | 트렌드 수용적, 실험적, 다양성 추구 |

### 축 4: 디테일 관심도 (Detail Attention) - M/B
| 코드 | 명칭 | 설명 | 특징 |
|------|------|------|------|
| **M** | Minimal (미니멀) | 간결함 추구 | 무채색 선호, 장식 최소화, 깔끔한 라인 |
| **B** | Bold (볼드) | 포인트와 디테일 중시 | 액세서리 활용, 패턴 선호, 레이어링 |

## 2.3 16가지 스타일 유형

### 유형 명명 규칙
`[표현방향][온도][변화][디테일]` = **유형 코드** / **유형 별명**

### 전체 유형 매트릭스

| 코드 | 별명 | 핵심 키워드 | 대표 스타일 |
|------|------|-------------|-------------|
| **IWSM** | 고요한 숲 | 편안함, 자연스러움 | 미니멀 캐주얼 |
| **IWSB** | 아늑한 서재 | 포근함, 개성 | 빈티지 캐주얼 |
| **IWNM** | 젠 마스터 | 절제, 탐구 | 노멀코어 |
| **IWNB** | 숨은 예술가 | 창의, 실험 | 아방가르드 캐주얼 |
| **ICSM** | 차분한 그림자 | 절제, 세련 | 다크 미니멀 |
| **ICSB** | 비밀의 정원 | 개성, 정교함 | 고딕 로맨틱 |
| **ICNM** | 미래에서 온 | 혁신, 간결 | 테크웨어 |
| **ICNB** | 밤의 예술가 | 실험, 강렬 | 스트리트 아방가르드 |
| **EWSM** | 햇살의 미소 | 친근, 깔끔 | 프레피 캐주얼 |
| **EWSB** | 봄날의 정원사 | 화사, 낭만 | 로맨틱 캐주얼 |
| **EWNM** | 트렌드 서퍼 | 최신, 편안 | 컨템포러리 캐주얼 |
| **EWNB** | 무대 위의 꽃 | 화려, 표현 | 맥시멀리즘 |
| **ECSM** | 도시의 건축가 | 세련, 모던 | 모던 미니멀 |
| **ECSB** | 밤의 사교가 | 우아, 강렬 | 글램 시크 |
| **ECNM** | 런웨이 스카우터 | 트렌디, 날카로움 | 하이패션 미니멀 |
| **ECNB** | 스타일 아이콘 | 대담, 선도 | 스테이트먼트 패션 |

## 2.4 유형 판정 로직

### 데이터 소스별 가중치

| 데이터 소스 | 판정 축 | 가중치 | 분석 포인트 |
|-------------|---------|--------|-------------|
| 카카오톡 메시지 | I/E, S/N | 30% | 대화 스타일, 이모티콘 사용, 쇼핑 언급 패턴 |
| 목소리 녹음 | W/C, I/E | 20% | 음성 톤, 말하기 속도, 에너지 레벨 |
| 얼굴/전신 사진 | W/C, M/B | 25% | 퍼스널 컬러, 체형, 현재 스타일 |
| 선호도 설문 | 전체 축 | 15% | 직접 선호 표현 |
| 행동 데이터 | S/N, M/B | 10% | 서비스 내 선택 패턴 |

### 판정 알고리즘 개요

```
1. 각 축별 점수 산출 (0-100)
   - 50 미만: 첫 번째 유형 (I, W, S, M)
   - 50 이상: 두 번째 유형 (E, C, N, B)

2. 경계값 처리 (45-55 구간)
   - "약한 성향"으로 표시
   - 예: "약한 E 성향의 EWSM"

3. 신뢰도 점수 계산
   - 데이터 충분성 기반
   - 최소 70% 이상 시 정식 유형 부여
```

## 2.5 유형별 콘텐츠 전략

### 각 유형에 제공되는 콘텐츠

1. **유형 설명 카드**: SNS 공유용 비주얼 카드
2. **스타일 가이드**: 유형별 추천 아이템, 컬러, 브랜드
3. **궁합 분석**: 다른 유형과의 스타일 케미
4. **성장 로드맵**: 인접 유형으로의 스타일 확장 가이드

# 3. 패션 평가 기능 상세 설계

## 3.1 기능 개요

### 한 문장 정의
사용자가 업로드한 사진을 다양한 페르소나가 평가하여 객관적인 스타일 피드백을 제공하는 기능

### 핵심 가치
- **문제**: 자신의 스타일을 객관적으로 평가받기 어려움
- **해결**: AI 페르소나를 통한 다양한 관점의 솔직한 피드백
- **차별점**: 단일 평가가 아닌 "다양한 시선"의 평가

## 3.2 페르소나 설계

### 기본 페르소나 (무료)

| 페르소나 | 캐릭터 | 평가 관점 | 말투 특성 |
|----------|--------|-----------|-----------|
| **패션 에디터 수진** | 30대 여성, 매거진 에디터 | 트렌드 적합성, 전체 조화 | 전문적, 건설적 |
| **스트리트 포토그래퍼 민수** | 20대 남성, 거리 패션 사진작가 | 개성, 분위기 | 쿨하고 직설적 |
| **스타일리스트 지현** | 40대 여성, 연예인 스타일리스트 | 체형 보완, 컬러 매칭 | 따뜻하고 세심 |

### 확장 페르소나 (프리미엄)

| 페르소나 | 캐릭터 | 평가 관점 | 활용 상황 |
|----------|--------|-----------|-----------|
| **첫인상 평가단** | 3명의 일반인 페르소나 | 첫인상, 호감도 | 소개팅, 면접 전 |
| **MZ 트렌드세터** | Z세대 인플루언서 | 힙함, SNS 감성 | 젊은 층 타겟 |
| **클래식 신사** | 50대 남성, 맞춤 정장 전문가 | 격식, 품격 | 비즈니스 상황 |
| **데이트 상대방** | 성별 선택 가능 | 이성에게 주는 인상 | 연애 상황 |

## 3.3 평가 프로세스

### Step 1: 사진 업로드
**입력 요구사항**
- 전신 사진 권장 (반신도 가능)
- 최소 해상도: 720x1280
- 지원 포맷: JPG, PNG, HEIC
- 최대 용량: 10MB

**자동 품질 체크**
- 얼굴/신체 인식 여부
- 조명 상태
- 블러 정도
- 배경 복잡도

### Step 2: 페르소나 선택
- 단일 페르소나 선택 (무료)
- 멀티 페르소나 선택 (프리미엄, 최대 5명)
- 상황 기반 자동 추천

### Step 3: AI 분석 & 평가 생성

**분석 항목**
| 항목 | 세부 내용 | 점수화 |
|------|----------|--------|
| 전체 조화도 | 상하의 밸런스, 컬러 매칭 | 1-10점 |
| 체형 적합도 | 실루엣, 비율 | 1-10점 |
| 트렌드 반영도 | 현재 트렌드 적합성 | 1-10점 |
| 개성 표현도 | 독창성, 스타일 일관성 | 1-10점 |
| 상황 적합도 | (상황 입력 시) TPO 적합성 | 1-10점 |

**평가 생성 형식**
```
[페르소나명]의 평가

✨ 첫인상: (한 문장)

📊 스타일 분석
- 잘된 점: ...
- 아쉬운 점: ...

💡 스타일링 팁
- 구체적 개선 제안 1-2가지

🎯 종합 점수: X/10
```

### Step 4: 결과 제공

**기본 결과**
- 선택한 페르소나별 평가 텍스트
- 종합 점수 및 레이더 차트
- 공유용 이미지 카드

**프리미엄 결과**
- 상세 분석 리포트
- 개선 전/후 시뮬레이션 (AI 생성)
- 추천 아이템 연결

## 3.4 기술 명세

### AI 모델 구성
| 기능 | 모델 | 용도 |
|------|------|------|
| 이미지 분석 | GPT-4 Vision | 의류 인식, 컬러 분석, 체형 분석 |
| 평가 생성 | GPT-4 | 페르소나별 평가 텍스트 생성 |
| 이미지 생성 | DALL-E 3 / Stable Diffusion | 개선 시뮬레이션 (선택) |

### 프롬프트 전략

**페르소나별 시스템 프롬프트 예시 (패션 에디터 수진)**
```
당신은 10년 경력의 패션 매거진 에디터 '수진'입니다.
- 말투: 전문적이지만 친근함, "~네요", "~어요" 체
- 관점: 트렌드와 실용성의 균형, 건설적 비판
- 피해야 할 것: 과도한 칭찬, 모호한 표현
- 강조할 것: 구체적인 아이템명, 실행 가능한 조언

평가 시 다음 순서로 분석하세요:
1. 전체적인 첫인상 (감정적 반응)
2. 아이템별 분석 (상의, 하의, 신발, 액세서리)
3. 컬러 조합 평가
4. 실루엣/비율 평가
5. 개선 제안 (구체적 아이템 추천 포함)
```

### 성능 요구사항
| 지표 | 목표치 | 측정 방법 |
|------|--------|-----------|
| 평가 생성 시간 | 10초 이내 | 사진 업로드~결과 표시 |
| 이미지 분석 정확도 | 95% | 의류 카테고리 인식 |
| 사용자 만족도 | 4.2/5.0 | 평가 후 설문 |

# 4. 패션 추천 기능 상세 설계

## 4.1 기능 개요

### 한 문장 정의
사용자의 멀티모달 데이터(텍스트, 음성, 이미지, 신체정보)를 분석하여 스타일 정체성을 파악하고 상황별 맞춤 패션을 추천하는 기능

### 핵심 가치
- **문제**: 일반적인 추천은 "나"를 반영하지 못함
- **해결**: 대화 패턴, 음성, 외모 등 다양한 데이터로 "나"를 입체적으로 분석
- **차별점**: 표면적 선호가 아닌 내면의 스타일 성향까지 반영

## 4.2 사전 데이터 수집 (프로필 구축)

### 4.2.1 카카오톡 메시지 분석

**데이터 수집 방식**
- 카카오톡 내보내기 기능 활용 (.txt 파일)
- 최소 1개 대화방, 1개월 이상 대화 권장
- 개인정보 자동 익명화 처리

**분석 항목**
| 분석 항목 | 추출 정보 | SIT 축 연관 |
|-----------|-----------|-------------|
| 이모티콘 사용 패턴 | 감정 표현 빈도/종류 | W/C (온도) |
| 대화 주도성 | 먼저 말 걸기 빈도 | I/E (표현) |
| 쇼핑/패션 언급 | 브랜드명, 스타일 키워드 | M/B, S/N |
| 문장 길이/구조 | 꼼꼼함 vs 간결함 | M/B (디테일) |
| 반응 속도 패턴 | 즉각 반응 vs 신중 반응 | S/N (변화) |

**분석 프롬프트 구조**
```
[Task] 카카오톡 대화 내역에서 사용자의 스타일 성향을 분석하세요.

[Input] 
- 익명화된 대화 내역 (최근 3개월)
- 사용자 식별자: USER

[Analysis Framework]
1. 커뮤니케이션 스타일 분석
   - 이모티콘/이모지 사용 빈도와 종류
   - 문장 길이 및 구조적 특성
   - 대화 주도성 (시작 vs 반응)

2. 패션 관련 언급 분석
   - 브랜드/아이템 언급 패턴
   - 쇼핑 관련 대화 맥락
   - 스타일 평가 표현 방식

3. 성격 특성 추론
   - 계획성 vs 즉흥성
   - 디테일 지향 vs 큰 그림 지향

[Output Format]
{
  "expression_score": 0-100,  // I(0) - E(100)
  "temperature_score": 0-100, // W(0) - C(100)
  "change_score": 0-100,      // S(0) - N(100)
  "detail_score": 0-100,      // M(0) - B(100)
  "confidence": 0-100,
  "key_insights": ["...", "..."]
}
```

### 4.2.2 목소리 녹음 분석

**데이터 수집 방식**
- 30초~2분 자유 발화 녹음
- 제시 주제: "최근 입은 옷 중 마음에 들었던 것"
- 또는: 일상 대화 음성 메모 업로드

**분석 항목**
| 분석 항목 | 추출 정보 | SIT 축 연관 |
|-----------|-----------|-------------|
| 음성 톤 | 높낮이, 따뜻함/차가움 | W/C |
| 말하기 속도 | 빠름/느림, 일정함/변화 | S/N |
| 에너지 레벨 | 활기/차분 | I/E |
| 표현 방식 | 구체적/추상적, 감정적/논리적 | M/B |

**기술 스택**
- STT: Whisper API
- 음성 특성 분석: Custom audio feature extraction
- 감정/톤 분석: GPT-4 기반 텍스트 + 음성 특성 결합 분석

# 9. 구현 로드맵

## Phase 1: MVP (8주)

**목표**: 핵심 기능 검증

| 주차 | 마일스톤 | 산출물 |

| 3-4주 | 패션 평가 개발 | 기본 페르소나 3종 평가 기능 |
| 5-6주 | SIT 판정 개발 | 사진 + 설문 기반 SIT 판정 |
| 7-8주 | 통합 테스트 | MVP 버전 배포 |

**MVP 범위**:
- 패션 평가: 기본 페르소나 3종
- SIT: 사진 + 설문 기반 판정 (카카오톡/음성 분석 제외)
- 추천: 기본 상황별 추천

| 13-14주 | 고도화 | 프리미엄 페르소나, 결과 공유 |
